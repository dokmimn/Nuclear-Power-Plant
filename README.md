# Nuclear Power Plant

A massive, highly volatile 9x9 nuclear reactor for Mindustry. Generates a staggering amount of power, but requires constant supervision.

## Features
* **High Power Output:** Generates 10,000 power per second.
* **Complex Fuel:** Requires both Thorium and Graphite to operate.
* **Thermal Runaway:** If the reactor loses its Cryofluid cooling OR its Graphite supply (moderator), it will begin to overheat.
* **Nuclear Meltdown:** If the reactor reaches 100% heat, it will explode, launching a devastating shockwave that wipes out the map and destroys the owner's core.
* **Custom Visuals:** Dynamic glowing core, heat overlays, and a custom explosion sound.

## How to use
1. Place the reactor and connect it to a **Graphite** and **Thorium** supply.
2. Connect a pipe with **Cryofluid**.
3. Connect power nodes to the output.
*Warning: Do not let the heat bar reach 100%!*

## Installation
1. Download the `.jar` file from the [Releases](https://github.com/dokmimn/Nuclear-Power-Plant/releases) page.
2. Place the `.jar` file in your Mindustry `mods/` folder.
3. Launch the game and enjoy!

## Compatibility
* Mindustry v8 (build 160+)
